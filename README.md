# Grid Forecast Guard

Can we trust today's forecast? Forecasting German electricity demand
and protecting the forecast against broken data.

## The question
1. What: Germany's electricity demand for every hour of tomorrow.
2. Who: a grid or energy-trading analyst planning how much power to buy.
3. When: made every day at 10:00; demand is known up to about 09:00.
4. Metric: average error in MW (MAE) and in % (MAPE).
5. Baseline: "tomorrow looks like the same hour last week".
